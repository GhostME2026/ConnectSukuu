Prepare payroll

Create a pending payroll record. It must be approved before payment.

Use the percentage for deductions that should scale with gross salary. Turn the deduction off to exclude it completely, or leave the percentage at 0% and enter a fixed amount.
Optional
If a percentage is above 0%, it is calculated from gross salary. If it is 0%, the fixed amount is used.
